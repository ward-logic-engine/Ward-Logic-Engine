# Security Policy

## Reporting Security Issues
If you discover a vulnerability or unauthorized use of this repository, contact Prince directly through the official communication channel listed in the repository README.  
Do **not** disclose vulnerabilities publicly until they have been reviewed and resolved.

## Unauthorized Use
This project is proprietary. Any unauthorized use, copying, modification, or distribution of the code is strictly prohibited.  
Violations may result in legal action under applicable intellectual property laws.

## Supported Versions
Only the latest public release of Ward Logic Engine is supported for authorized partners.  
Older versions are not maintained or licensed for use.

| Version | Status |
|----------|---------|
| Latest release | ✅ Supported |
| Older releases | ❌ Not supported |

## Security Commitment
Prince and authorized collaborators maintain strict control over access, commits, and distribution.  
All contributors must comply with the Contributor Agreement and License terms.
